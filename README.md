# FamilyVault - Система хранения семейных документов

Консольное приложение для учета и управления семейными документами.

## Возможности
- добавление документов;
- просмотр всех документов;
- поиск по уровню доступа;
- проверка статуса документа;
- сохранение и загрузка данных в JSON.

## Структура проекта
- main.py – точка запуска;
- documents.py – работа с документами;
- storage.py – сохранение и загрузка данных;
- utils.py – вспомогательные функции;
- data/ – JSON-файлы данных;
- tests/ – автоматизированные тесты.

## Требования
- Python 3.x;
- pytest;
- flake8.

## Основные сущности и классы

### Класс `Family` (Семья)
Описывает семью, которой принадлежат документы.
*   **Атрибуты:** `id`, `name`.
*   **Методы:** `__str__()`, `from_data()`, `to_dict()`.

### Класс `Document` (Документ)
Описывает документ, хранящийся в системе.
*   **Атрибуты:** `id`, `title`, `category`, `family` (объект `Family`), `access`, `date_added`.
*   **Методы:** `__str__()`, `change_access()`, `is_valid_access()` (статический), `from_data()`, `to_dict()`.

### Взаимодействие объектов
Объект `Document` содержит ссылку на объект `Family` (композиция). Это позволяет получать имя семьи напрямую через `document.family.name`, не храня в документе `family_id` как отдельное поле в памяти.
При сохранении в JSON связь преобразуется в `family_id`, а при загрузке — восстанавливается в объект `Family`.
