# FamilyVault - Система хранения семейных документов

## Назначение

Приложение предназначено для централизованного хранения, каталогизации и управления семейными документами (паспорта, свидетельства, дипломы, медицинские карты). Оно помогает навести порядок в бумагах и обеспечить быстрый доступ к нужной информации.

## Целевая аудитория

Семьи, отдельные пользователи, желающие систематизировать личные и семейные документы, а также люди, ведущие архив важных бумаг.

## Предметная область

Управление личными документами, архивация, категоризация и обеспечение сохранности личной информации.

## Основные сущности

- Семья (Family)
- Документ (Document)
- Категория (Category)
- Доступ (Access)

## Основные функции

- добавление нового документа в базу;
- просмотр списка всех документов;
- поиск документов по категории;
- удаление документа (в перспективе).

## План развития

На следующих этапах планируется:

- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
